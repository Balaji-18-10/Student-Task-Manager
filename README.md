# Student Task Manager 📚

A modern student task management web application built to help students organize tasks, track deadlines, and manage productivity efficiently.

## Features ✨
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Deadline tracking
- Firebase authentication
- Cloud Firestore database storage
- Responsive UI

## Tech Stack 🛠️
- React.js
- Vite
- Firebase
- Firestore
- CSS / JavaScript

## Installation 🚀

Clone the repository:

```bash
git clone https://github.com/yourusername/student-task-manager.git
```

Navigate to project folder:

```bash
cd student-task-manager
```

Install dependencies:

```bash
npm install
```

Create environment file:

```bash
.env
```

Add Firebase configuration keys.

Run the project:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
